# Expo Preferences

This file exists to support migrations from older OpenCode/AI agents that had a `CLAUDE.md` at the project root. This was Claude Code's project rules file, and it now serves as a reference for agents that prefer to use this file.

## Use Cases

If a subagent or tool specifically requires a `CLAUDE.md` file and cannot work without it, this file provides the necessary context in the format the agent expects.

**Note**: For this project, the main project rules and guidelines are fully documented in `opencode/AGENTS.md` at the project root level.
