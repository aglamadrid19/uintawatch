The Path Forward

Uinta Watch — Community Wildfire Detection

An open-source, community-driven early wildfire detection network. Solar-powered LoRa mesh sensors deployed across Utah's wildlands — working when nothing else does.

Solar-Powered
Self-sustaining nodes running on 5V solar + 18650 Li-ion, with 2–3 day battery autonomy.
Mesh Network
Peer-to-peer LoRa mesh at 915MHz. Every node is a relay. No cell signal required.
Internet Bridge
Gateway nodes with cellular/satellite backhaul bridge the mesh to the cloud every 5–10 km.
Real-Time App
React Native app: live readings, fire alerts, community reporting. Open source and extensible.
