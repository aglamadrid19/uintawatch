# Hallmark Redesign — Uinta Watch

## Design Direction
- **Audience**: Utah community members, wildfire preparedness activists, tech-curious neighbors
- **Use case**: Drive network signups, sensor deployments
- **Tone**: Editorial-utilitarian — magazine copy, functional but sophisticated

## Theme (Custom Editorial)
- Paper: warm off-white (#FAF8F5)
- Ink: deep charcoal (#1A1A1A)
- Accent: terracotta/rust (#C45A3B)
- Display: serif (Playfair Display or DM Serif Display)
- Body: grotesk sans (Archivo or DM Sans)

## Key Hallmark Rules Applied

### NEVER DO
1. Centered-everything hero
2. Inter/Poppins/Lato as display font
3. Italic headings
4. `transition: all`
5. Fabricated metrics
6. Two-line CTA buttons
7. Purple gradients on text

### ALWAYS DO
- Asymmetric hero layout
- Typography-led design
- All 8 button states
- Mobile responsive (320-768px)
- `overflow-x: clip`
- Prose max-width: 65ch
